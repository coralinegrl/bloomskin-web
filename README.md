```
npm install
```

```
npm run serve
```

### Compiles and minifies for production
```
npm run build
```

### Customize configuration
See [Configuration Reference](https://cli.vuejs.org/config/).

## Backend API

Se agrego una API Express en `backend/` con PostgreSQL + JWT + Brevo.

Guia rapida:

1. `cd backend`
2. `npm install`
3. Copia `.env.example` a `.env`
4. Ejecuta `backend/sql/schema.sql` en PostgreSQL
5. `npm run dev`
